SLOW BREATH - installable web app
=================================

What is in this folder
  index.html               the app
  manifest.webmanifest     name, colours and icons (this is what makes it installable)
  sw.js                    saves the app on the phone so it works offline
  icon-192.png, icon-512.png, icon-maskable-512.png

1. Put the folder online (free, no code)
  The app has to be served from an https address once; after that it lives on your phone.
  Unzip this file first, then use any static host. Two easy ones:

  Netlify Drop:  open https://app.netlify.com/drop and drag the unzipped folder onto the page.
                 Create a free account if it asks, so the site is kept.
  Cloudflare Pages: Workers & Pages > Create > Pages > Upload assets, then drop the folder.

  You get an address like https://something.netlify.app

2. Install on your Samsung phone
  Open that address in Chrome, tap the three-dot menu, then "Install app"
  (or "Add to Home screen"). Open it once while online. After that it also works offline.

3. Updating later
  Replace the files on the host. In sw.js change CACHE = "slow-breath-v1" to "slow-breath-v2"
  so phones pick up the new version.

Notes
  - Your settings are saved on the phone, inside the app.
  - Vibration works in Chrome on Android. Use "Try it" in the settings to check.
  - The cello sound is generated by the app, so it needs no audio files.
